Le fascicule HESTIM demande d'étudier les robots myCobot 280 Pi et mechArm 270 Pi. Les diagrammes ci-dessous présentent une analyse générique d'un bras robotisé pédagogique. Avant le rendu final, votre groupe doit confirmer le modèle réellement retenu et vérifier les performances dans sa documentation technique ou pendant l'observation au laboratoire.

À vérifier avant la remise

  • Choisir clairement le modèle étudié : myCobot 280 Pi ou mechArm 270 Pi, ou préciser que la comparaison porte sur les deux.
  • Observer la base, les articulations, le préhenseur et l'interface de commande.
  • Compléter les niveaux chiffrés avec la documentation constructeur ou les mesures du TP.
  • Vérifier les fonctions avec les notes de cours et les consignes de l'enseignant.
  • Ajouter les noms des membres du groupe, la date et le modèle exact en page de garde si nécessaire.
